4K Urban Concrete Textures & Materials (Lite Version)
================================================================================

Thank you for downloading this sample pack! 

This package includes 3 high-quality, game-ready concrete textures with full PBR 
maps pre-configured for both Unity Built-in Render Pipeline and Universal Render 
Pipeline (URP).

--------------------------------------------------------------------------------
PACKAGE CONTENTS
--------------------------------------------------------------------------------
- 3 Texture Sets
     Aged_Plaster_Fractured
     Concrete_Aggregate
     rough_concrete_floor

- 5 PBR Maps Per Texture Set
     Ambient Occlusion (_ao)
     Diffuse  Albedo (_diffuseOriginal)
     Height  Displacement (_height)
     Normal Map (_normal)
     Smoothness (_smoothness)

- Pre-configured Materials
     Built-in Render Pipeline Materials
     Universal Render Pipeline (URP) Materials
